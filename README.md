# ربات نرخ ارز / طلا / کریپتو (Telegram Price Bot)

آماده برای دیپلوی روی **Railway**.

## نحوه دیپلوی روی Railway

1. یک ریپازیتوری جدید در GitHub بساز و این فایل‌ها را آپلود کن:
   - `bot.py`
   - `requirements.txt`
   - `Procfile`

2. به [railway.app](https://railway.app) برو و پروژه جدید بساز → **Deploy from GitHub repo**

3. در بخش **Variables** متغیر زیر را اضافه کن:
   ```
   BOT_TOKEN = توکن ربات تلگرامت
   ```
   (اختیاری)
   ```
   FOOTER = @yourusername
   CACHE_SECONDS = 20
   ```

4. در Settings سرویس، نوع را روی **Worker** بگذار (نه Web).

5. دیپلوی کن. لاگ‌ها را چک کن تا پیام `bot started` را ببینی.

## دستورات ربات

- `/start` یا `/rates`
- `دلار` / `یورو` / `طلا` / `سکه` / `تتر` / `بیتکوین` ...
- `100 دلار`
- `100 تون دلار` (تبدیل)
- `نرخ ارز` یا `لیست` (لیست کامل)

## نکات

- فونت‌ها و تصاویر پس‌زمینه به صورت خودکار در `/tmp` دانلود و کش می‌شوند.
- توکن را هرگز در کد هاردکد نکن.
